# Quantt Tech

### Learn • Build • Contribute • Grow 🚀

Quantt Tech is a student-led technology community focused on building real-world projects, learning through practical experience, and contributing to open source.

## What We Build

- ⚛️ Web Development
- 🤖 AI / Machine Learning
- 🔐 Cyber Security
- ☁️ Cloud & DevOps
- 📱 App Development
- 🧪 Testing & QA
- 🎨 UI/UX
- 💻 Open Source

## Open Source Program

Our projects are organized by contribution level:

### 🟢 Basic
Beginner-friendly projects and issues designed for your first open-source contribution.

### 🔵 Build
Projects where contributors work on features, improvements, and real-world development tasks.

### 🟣 Pro
More complex projects involving advanced features, architecture, security, or larger contributions.

## How to Contribute

1. Explore our repositories.
2. Choose a project matching your skill level.
3. Find an issue you want to work on.
4. Read the project's `CONTRIBUTING.md`.
5. Comment on the issue before starting.
6. Fork the repository and create a branch.
7. Make your changes.
8. Open a Pull Request.
9. Get your contribution reviewed and merged.

## Our Goal

We want students to move beyond tutorials and gain experience by actually:

**Learning → Building → Contributing → Collaborating**
